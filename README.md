# Inheritance in Java

## Description
This program demonstrates inheritance in Java using a parent class (`Animal`) and a child class (`Dog`). The child class inherits the `eat()` method from the parent class and defines its own `bark()` method.

## Concepts Used
- Object-Oriented Programming (OOP)
- Inheritance
- Parent and child classes
- `extends` keyword
- Methods and objects

## Output
```text
Animal is eating
Dog is barking
```

## How to Run
Compile the program:
```bash
javac Inheritance.java
```

Run the program:
```bash
java Inheritance
```

## Purpose
Created for Java learning, college lab practice, and understanding OOP concepts.
